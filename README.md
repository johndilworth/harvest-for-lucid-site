# Harvest for Lucidchart: concept site

**Concept mockup for pitch purposes.** A static marketing site that pitches *Harvest* as a Lucid Suite add-on for
Lucidchart, styled after lucid.co's public look and feel (no Lucid logo or asset files are used). Pages are
`noindex,nofollow` (meta tag + `X-Robots-Tag` header + `robots.txt` disallow-all). The beta form never submits.

- Live: https://harvest-for-lucid.netlify.app (Netlify site `harvest-for-lucid`, Git-linked to this repo:
  production = `main`, deploy previews for PRs into `main`)
- Pages: `/` · `/how-it-works` · `/pricing` · `/beta`

## Layout
```
site/                 published as-is (no build step)
  index.html, how-it-works.html, pricing.html, beta.html   generated by tools/build_pages.py
  assets/site.css, site.js, favicon.svg
  img/*.webp          real visuals from the design-loop sample run (screens + Lucid exports)
tools/                page generator (shared nav/footer), original inline SVG icons, local pretty-URL server
journey/              Harvest review tooling (copied from design-loop-sample-prototype) + cycle artifacts
```

```bash
python3 tools/build_pages.py        # regenerate site/*.html after editing tools/page_*.py
python3 tools/serve.py 8765         # local preview with Netlify-style pretty URLs
npm ci && npx playwright install chromium
node journey/capture.mjs --cycle N --base-url https://harvest-for-lucid.netlify.app   # see journey/README.md
```

## Sources for the numbers on the site
All figures come from the design-loop sample run (github.com/johndilworth/design-loop-sample-prototype, PRs #1–#3)
and its Lucid cost report: 3 cycles, 32 feedback items (11 must / 21 try), 3 PRs, 32/32 items in the next PR's table;
Lucid side ~5–6k tokens per item (measured, cycle 3); whole cycle ~7.8k–13.8k tokens per item (modeled); batching vs
chat not proven. No customer logos, testimonials, prices or availability claims.
